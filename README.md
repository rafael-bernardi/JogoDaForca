# 🪓 Jogo da Forca em Java

Projeto em Java desenvolvido para praticar conceitos de Lógica de Programação, Manipulação de Strings, Arrays, Coleções Dinâmicas e Tratamento de Exceções/Entradas.

## 🚀 Evolução do Projeto

- **Versão 1:** Estrutura básica do jogo, escolha aleatória de palavras e renderização da palavra oculta.
- **Versão 2:** Limite de erros (5 tentativas) e interface gráfica em ASCII da forca dinâmica.
- **Versão 3:** Histórico de palpites com `ArrayList` e validação contra letras duplicadas sem penalização.
- **Versão 4 - final :**
  - **Menu de Categorias:** Suporte para Frutas, Países, Animais e Cores.
  - **Validação de Inputs:** Tratamento de entradas inválidas no menu e proteção contra entradas vazias durante as jogadas.

## 🛠️ Tecnologias Utilizadas
- Java 17+
- `java.util.Scanner`
- `java.util.Random`
- `java.util.ArrayList`
