# 🪓 Jogo da Forca em Java

Projeto em Java desenvolvido para praticar manipulação de `String`, `Arrays`, controle de fluxo e lógica de programação.

## 🚀 Funcionalidades
- **Versão 1.0:** 
  - Escolha aleatória de palavras a partir de uma lista pré-definida de frutas.
  - Exibição dinâmica da palavra oculta com traços (`_`)
  - Leitura e verificação de chutes do jogador letra por letra.
  - Validação de vitória ao completar todas as letras.
  - **Versão 2.0:** Limite de 5 erros e arte ASCII da forca dinâmica[cite: 1].
- **Versão 3.0 (Atual):** 
  - Registo e exibição do histórico de letras já tentadas (`ArrayList`).
  - Validação para impedir palpites repetidos sem penalizar o jogador com erros.

## 🛠️ Tecnologias
- Java SE (JDK 17+)
- `java.util.Scanner`
- `java.util.Random`
